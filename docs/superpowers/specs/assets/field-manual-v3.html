Sheet 03 / 06 · Pure Storage / Everpure · 2023–24

Rollout safety

Schedule C — Disruption manager
EmployerPure Storage / Everpure
RoleMember of Technical Staff 2
GoalNever disrupt a whole group at once

General notes

  1. Pure's internal disruption-manager service: the rollout-safety control point Dominator consults before a disruptive update.
  2. Pushed to a whole group, a disruptive image restarts every VM at once: test availability drops to zero, and a bad image breaks tests.
  3. Per-group concurrency budget: a semaphore held in Consul. Only N machines in a group are disrupted at a time.
  4. Test-aware gating: a request waits until the tests running on that machine finish. Canary first, fast revert.
  5. Pluggable check / request / cancel interface, so other teams can write their own by implementing three methods.
  6. ~7× fewer DB reads via a 100 s TTL Redis cache plus negotiated backoff.
